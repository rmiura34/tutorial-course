# 動画・ビデオコース選定ガイド

動画は全Dayの必須要件ではありません。文章、Command例、成功状態、Hands-onだけで十分に学べる場合は`videos: []`とし、画面にも動画セクションを出しません。

## 優先順位

1. 製品・フレームワーク提供元の公式動画
2. 公式ドキュメントが紹介する動画コース
3. 信頼できる教育組織の動画
4. コース運営者が制作する短い補助動画

動画だけで仕様を断定しません。仕様確認が必要な場合は現在の公式ドキュメントも置き、日本語公式版を優先します。長い動画は「最初の35分」「該当チャプター」のように視聴範囲を指定し、必須か任意かを明記します。

## 1リソースの必須情報

- 視聴ページの実URL
- 正式タイトルと提供元
- 何を確認する動画かという日本語説明
- 視聴時間または指定範囲
- 受講後に行うハンズオンとの関係
- 埋め込み可能な場合のみ、Cookieを抑えた`embedUrl`

「動画をここに入れる」のような仮置きは公開しません。埋め込みできない公式コースは、説明付きカードから新しいタブで開けるようにします。

## 補助動画を制作する場合

- 1本3〜7分、1本につき1操作または1概念
- 完成形 → 今日の目標 → 操作 → 失敗例 → 復旧 → 課題の順
- 日本語字幕、全文トランスクリプト、入力コマンドを添付
- WindowsとMacで異なるショートカットを記載
- 自動再生を使わず、タイトルと字幕を設定

## 公開前チェック

- [ ] リンク先が開く
- [ ] タイトルと提供元が一致する
- [ ] 説明文だけで視聴目的が分かる
- [ ] 180分の時間割に収まる
- [ ] 動画がなくてもTask・Command・成功状態を理解できる、または動画が必要な理由が明確
- [ ] 動画の内容を確かめるクイズまたは実装がある
- [ ] 公式資料と内容が矛盾していない
