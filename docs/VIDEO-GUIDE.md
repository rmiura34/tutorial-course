# 動画制作ガイド

## 長さ

- 1本3〜7分
- 1本につき1つの操作または概念
- 30分講義を1本にまとめない

## 基本構成

1. 0:00 完成形を見せる
2. 0:20 今日できるようになること
3. 0:40 実際の操作
4. 3:00 よくある失敗
5. 4:00 失敗から戻る
6. 5:00 受講者が行う課題

## 必須要素

- 日本語字幕
- 全文トランスクリプト
- 動画で入力したコマンド
- WindowsとMacで異なるショートカット
- 完了時の画面
- エラーが出たときの戻り方

## 埋め込み

公開先の動画IDが確定したら、レッスンページの`video-screen`をYouTubeまたはVimeoの`iframe`へ差し替えます。自動再生は使わず、タイトルと字幕を設定します。
