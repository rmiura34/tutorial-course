# Python scraper practice instructions

- Read the active Day 11 or Day 12 task first.
- Use fixture HTML before making any network request.
- Add timeout, retry limit, user agent, and rate-limit reasoning before live access.
- Check terms of service and robots.txt before scraping a site.
- Deduplicate using a documented stable key.
- Run `python3 -m unittest discover -s tests -v`.
- Never store authenticated cookies, personal data, or production credentials.
