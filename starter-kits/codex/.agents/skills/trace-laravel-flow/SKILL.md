# Trace a Laravel request

1. Confirm the Laravel version and target URL/method.
2. Keep the investigation read-only.
3. Find Route, Middleware, Controller, FormRequest, Service, Model, Migration, Test, and Response.
4. Record the exact file and method at each verified step.
5. Record tables, columns, relationships, external calls, queue jobs, events, and logs.
6. Separate verified facts, hypotheses, and unknowns.
7. Finish with risks and candidate change points. Do not implement.

Use `references/output-template.md` for the final report.
